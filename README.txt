NUTRIUPC - FLUJO MAXIMO WEB INTERACTIVO

1. Abra index_interactivo.html en Google Chrome o Microsoft Edge.
2. Construya o cargue una red.
3. En Calcular flujo, seleccione fuente y sumidero.
4. Use el slider para recorrer el estado inicial y cada iteración.
5. Naranja = camino de la iteración; verde = flujo anterior; rojo = saturada; gris = sin flujo.
6. No necesita instalación ni conexión a Internet.
